# todolist

## 本文件职责
- 只记录本轮目标、当前待办、执行状态、验证结果、下一步
- 长期规则写入 project_rules.md
- 项目结构与核心链路写入 project_framework.md

- 每次动手前先补充“本轮目标 / 待办 / 风险点”
- 每次改动后回写“已完成 / 验证结果 / 下一步”
- 如果项目结构或关键链路发生变化，同时更新 project_framework.md
